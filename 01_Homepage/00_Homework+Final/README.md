# YGL — Monthly AI Collective

윤·길·이 세 사람이 운영하는 월간 AI 스터디 운영 포털입니다. Node.js(Express) 서버가 화면을 제공하고 데이터를 저장합니다.

## 실행

1. Node.js가 설치되어 있어야 합니다 (https://nodejs.org).
2. 이 폴더에서 터미널을 열고 패키지를 설치합니다.
   ```
   npm install
   ```
3. 서버를 실행합니다.
   ```
   npm start
   ```
4. 브라우저에서 `http://localhost:3000` 을 엽니다.
5. 종료하려면 터미널에서 `Ctrl + C`.

세 사람이 각자 다른 컴퓨터에서 접속하려면, 서버를 실행하는 컴퓨터의 네트워크 주소(예: `http://192.168.0.5:3000`)로 접속하면 됩니다.

## 제공 기능

- Overview: 실행 아이템·완료 현황·멤버별 진척도·최다 득표 후보일
- 일정 투표: 월 선택, 후보 날짜 추가, 멤버별 복수 투표, 투표 현황
- 회의록: 회의록 작성·수정·삭제·검색 및 상세 보기
- 실행 아이템: 담당자·분류·목표일·진척도 관리, 검색과 멤버 필터
- 멤버: 윤·길·이별 아이템과 평균 진척도
- AI 라이브러리: 참고 도구/자료 링크 추가·수정·삭제 및 프롬프트 템플릿 복사
- 운영 가이드: 월간 운영 리듬, 권장 아젠다, 데이터 백업/복원
- JSON 백업/가져오기

## 데이터 저장 및 공유

입력 데이터는 서버의 `data/store.json` 파일에 저장됩니다. 세 사람이 같은 서버에 접속하면 투표·회의록·아이템이 모두 공유되어 자동으로 동기화됩니다. 서버가 꺼져 있으면 사이트도 접속되지 않으니, 사용하는 동안에는 서버를 계속 켜 두어야 합니다. JSON 파일 내보내기/가져오기 기능은 백업용으로 그대로 남아 있습니다.

## 폴더 구성

| 경로 | 역할 |
|---|---|
| `server.js` | Express 웹 서버. 화면 파일을 제공하고, 데이터 저장/조회 API를 처리합니다. |
| `public/index.html`, `public/styles.css`, `public/app.js` | 기존 화면(디자인·기능)을 그대로 담은 프런트엔드 파일. |
| `data/store.json` | 실제 저장되는 데이터 파일 (서버가 자동 생성). |
| `.env` | 서버 설정값(포트 번호, 추후 외부 API 키 등)을 담는 파일. Git에는 올리지 않습니다. |
| `package.json` | 설치할 패키지와 실행 명령어 정의. |

## 샘플 데이터

초기 화면에 보이는 실행 아이템과 회의록은 기능 확인을 위한 예시 데이터입니다. 실제 스터디 상황에 맞게 수정하거나 운영 가이드의 `샘플 데이터 초기화`로 다시 시작할 수 있습니다.
